# Relatorio tecnico: metricas reais de pipeline CI/CD

Este relatorio sera preenchido apos a coleta das execucoes reais do GitHub
Actions. A versao final deve conter:

- links das execucoes reais;
- IDs reais dos workflows;
- commits usados no experimento;
- explicacao das variacoes;
- graficos gerados a partir dos CSVs;
- analise critica de desempenho, estabilidade, gargalos e limitacoes.
